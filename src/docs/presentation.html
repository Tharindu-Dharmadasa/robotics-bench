01 · Application Purpose

Robotics Bench:
Interactive 3D Electronics & Fault Lab

A browser-based 3D hardware simulator designed to bridge the gap between theoretical circuit diagrams and physical robotics prototyping—without the cost or risk of burning real components.

Risk-Free Hardware Learning

Students and engineers can test wiring mistakes, overcurrent loads, and missing protection components safely in 3D.

Visual Cause & Effect

Demonstrates why every resistor, capacitor, and diode exists by visualizing current flow and physical failure reactions.

Zero-Setup Accessibility

Runs 100% in the browser with no backend servers, installations, or physical lab kits required.

02 · Main Project Requirements

Core Functional Goals

Four primary requirements guided the design and engineering of the platform.

1. Authentic 3D Hardware & Assembly

  • Model 13 industry-standard robotics modules with accurate form factors, silkscreens, and removable parts.
  • Enforce step-by-step assembly workflow: component placement, soldering, power connection, and code execution.

2. Real-Time Fault & Physics Simulation

  • Trigger realistic visual and audio feedback (arc flash, sparks, charring, smoke) when critical parts are removed or misconfigured.
  • Display clear Serial Monitor diagnostics explaining what broke and why.

3. Interactive Board Controls

  • Provide live test instruments per board: PWM sliders, IMU tilt controls, rotary encoder steps, and ultrasonic distance targets.

4. Open Experiment Sandbox

  • Include a customizable breadboard workbench where users can freely place parts, route jumper wires, and test custom circuits.
03 · Technology Stack

Modern Client-Side Architecture

Lightweight, modular frontend stack built for 60fps WebGL rendering and instant deployment.

Frontend & UI

  • React 19 + TypeScript: Strict type-safe component and circuit netlist state management.
  • Tailwind CSS: Crisp retro-hardware workbench interface and responsive HUD panels.
  • Vite: Fast bundling and single-command production builds.

3D Graphics & Physics

  • Three.js + React Three Fiber: Real-time WebGL hardware rendering and imperative 60fps animation loops.
  • Procedural Canvas Textures: Dynamic PCB silkscreens, copper traces, and live OLED screen rendering.

Simulation & Audio

  • Union-Find Netlist Solver: Sub-millisecond electrical continuity, short-circuit, and load evaluation.
  • Web Audio API: Browser-native synthesized electrical pop and sizzle effects with zero external audio files.
04 · System Architecture

How All Features Work Together

Discrete React state controls circuit rules while Three.js handles continuous 60fps physics.

1. User Interaction Places parts, toggles pins, routes wires, or edits values
→
2. Netlist & Rule Engine Evaluates continuity, current limits, and fault severity
→
3. 60fps 3D Viewport Animates current flow, servos, OLEDs, or burnout sparks
→
4. Telemetry & HUD Logs live Serial output and educational fault diagnostics

Zero-Lag Rendering

All smoke particles, sparks, and electron pulses run directly on GPU refs inside useFrame without triggering React re-renders.

Clean State Recovery

Repairing a damaged component restores its original Three.js material properties and resets circuit telemetry cleanly.
